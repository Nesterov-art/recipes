# APK №7 — release candidate

Подготовка: 1 ноября 2026 года. Ветка: `stage-7.6-unified-backup`, база UX/UI-пакета: `ee09306`.

Сборка этим документом не запускается и не считается выполненной. Нужны отдельное разрешение на EAS Build и отдельное согласование установки. Основной эмулятор `emulator-5554` не использовать для проверок этого этапа.

## Параметры

- Android application ID: `com.neyroshi.monorec`.
- Профиль EAS: `preview`; internal distribution; `android.buildType: apk`.
- Версия приложения: `1.0.0`; runtime policy: `appVersion`.
- `cli.appVersionSource: remote`, `preview.autoIncrement: true`.
- «APK №7» — название тестовой итерации, а не принудительное значение versionCode. Следующий versionCode определяет EAS.
- app.json, eas.json, нативные зависимости, permissions, storage keys и форматы копий этим UX/UI-пакетом не изменяются.
- Для обновления APK №6 необходимо сохранить application ID и прежнюю подпись Android и получить более высокий versionCode. Подпись конечного файла и сохранность данных проверяются после сборки; одно совпадение ID этого не доказывает.

Команда для будущего запуска из корня проекта, только после разрешения:

```powershell
npx eas-cli@latest build --platform android --profile preview
```

Не выбирать development, не создавать новый keystore взамен прежнего, не выполнять EAS Update, submit или PWA deploy.

## Проверка APK после создания

Использовать отдельное тестовое устройство/AVD с APK №6 и синтетическим профилем. До обновления сохранить копию и эталон: рецепты, любимое, история/заметки, порядок/количества/галочки покупок и настройки.

1. Установить APK №7 поверх №6 с той же подписью, без uninstall, очистки данных и Wipe Data. Сравнить профиль с эталоном; онбординг не должен запускаться заново.
2. Холодный запуск без Metro и Expo Go; закрытие и повторное открытие приложения.
3. Создать, изменить и удалить тестовый рецепт. Проверить отмену удаления и сохранение после перезапуска.
4. Покупки: ручное добавление, перенос ингредиентов, объединение, checkbox, редактирование, отмена свайпа, удаление и long-press drag. Проверить обычную прокрутку длинного списка, последнюю карточку и сохранение порядка.
5. Четыре вкладки, повторный выбор «Выбора», вложенные экраны и возвраты. Проверить активную капсулу, клавиатуру, Safe Area и Android gesture/three-button navigation.
6. Светлая, тёмная и системная темы; RU/EN; большой системный шрифт; Reduce Motion. Проверить заголовки с оранжевой пунктуацией и отсутствие обрезания.
7. Создать полную резервную копию через выбор папки: отмена, успешное сохранение, повторное имя и дата выгрузки. Проверить содержимое файла.
8. Только на изолированном профиле: выбрать файл, проверить preview, отменить без изменений; затем подтвердить восстановление. Проверить все области профиля после перезапуска и повторное восстановление без удвоения покупок.
9. На изолированных данных проверить старый `recipes-backup v1`: добавление с preview, без замены остальных областей.

Результаты native-проверок нельзя заменять результатами WebKit/Chromium или Expo Go. Поисковые, storage и gesture-регрессии, выполненные в браузере, являются отдельным уровнем проверки.

- **AUD-001 / Medium / Navigation:** отсутствующий рецепт даёт пустой экран в `src/app/recipe/[id].tsx` и `src/app/shopping-select.tsx`. Нужны понятное состояние и безопасный возврат.
