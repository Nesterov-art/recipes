# monorec

Минималистичная книга рецептов от **Neyroshi**. Сохраняйте блюда, находите идею для готовки и собирайте продукты в одном списке.

**[Открыть PWA](https://neyroshi-recipes.expo.app)**

Приложение развивается для Android, iOS и Web/PWA. Основные пользовательские данные хранятся на устройстве.

## Состояние проекта

| Направление | Статус |
| --- | --- |
| Web/PWA | Опубликована по ссылке выше, работает независимо от компьютера разработчика |
| Android | Тестовая APK №8, версия 1.0.0 / versionCode 8, проверена на Android 17 / API 37 |
| iOS | Подготовлены конфигурация и файловый адаптер, JS-сборка проходит; нативная проверка на устройстве предстоит |
| Исходники в `main` | Более ранняя версия на Expo SDK 57, React 19.2 и React Native 0.86 |
| Текущая разработка | Локальная ветка `stage-7.6-unified-backup` на Expo SDK 58, React 19.3 и React Native 0.88; ветка ещё не опубликована на GitHub |

Ниже описана текущая разрабатываемая версия Monorec. Команды клонирования получают опубликованную ветку `main`. Последние изменения интерфейса, хранения и нативных сборок находятся в ветке разработки.

## Возможности текущей разработки

### Четыре вкладки

- **Выбор** — помогает решить, что приготовить из своей книги.
- **Рецепты** — хранение блюд, поиск, категории, любимые и история приготовлений.
- **Покупки** — продукты, количества, отметки и подбор рецептов по списку.
- **Настройки** — оформление, язык, поведение покупок, резервные копии и информация о приложении.

### Книга рецептов

- Создание, редактирование и удаление с подтверждением.
- Название, время приготовления, категория, ингредиенты и шаги.
- Добавление по ссылке Monorec или со страницы рецепта, предпросмотр и проверка дубликатов.
- Поиск по названию и ингредиентам.
- Фильтры по категориям, любимым и быстрым блюдам до 15 минут.
- Сортировка по новизне и названию.
- Статистика книги и переход к истории приготовлений.

Основные сценарии выполняются локально. Для загрузки рецепта с сайта нужен интернет; доступность импорта зависит от страницы и ограничений сайта.

### «Что приготовим?»

Smart Random выбирает из всей книги. Поиск и фильтры вкладки «Рецепты» не сужают этот выбор.

Алгоритм повышает шанс блюд, которые ещё не готовили или готовили давно, и снижает шанс недавно приготовленных. При наличии альтернатив один рецепт не предлагается два раза подряд. Кнопка «Другой вариант» позволяет продолжить поиск идеи.

### Готовка и история

- Пошаговый режим с прогрессом и завершением приготовления.
- Отдельная запись каждого приготовления с датой и необязательной заметкой.
- Число приготовлений, последняя дата и заметка на странице рецепта.
- Общая история и история отдельного блюда.
- Сохранение ранее записанных оценок в данных и резервных копиях.

Для рецепта без шагов доступна быстрая отметка «Я приготовил».

### Список покупок

- Ручное добавление и перенос выбранных ингредиентов из рецепта.
- Отдельные карточки продуктов с названием и количеством.
- Редактирование и удаление через действия свайпа влево.
- Перестановка долгим нажатием на свободную область карточки.
- Отметка купленного, снятие отметки и удаление отмеченных позиций.
- Настройка переноса купленных продуктов вниз или сохранения их места.
- Сохранение количества, единиц, галочек и порядка между запусками.

Нормализация учитывает регистр, пробелы и известные формы названий, например «яйцо» / «яйца» и «картофель» / «картошка». Разные продукты, например «лук» и «зелёный лук», сохраняются отдельно.

Совместимые количества суммируются с преобразованием кг ↔ г и л ↔ мл. Несовместимые единицы остаются отдельными позициями. Известные пояснения «по вкусу» и «для жарки» сохраняются для отображения.

### «Что можно приготовить?»

Подбор сопоставляет названия ингредиентов с **всеми** продуктами списка покупок, включая отмеченные. Результаты сортируются по доле совпадений, затем по их количеству. Для блюда видны время, совпадения и недостающие ингредиенты.

Проверяется наличие названий в списке. Достаточность количества и фактические запасы дома не определяются.

### Настройки и оформление

- Светлая, тёмная и системная темы.
- Русский и английский языки.
- Размер текста следует системным настройкам.
- Повтор онбординга через «Знакомство».
- Экран «О Monorec» с версией, разработчиком и обратной связью.
- Минималистичный интерфейс с иллюстрациями, скруглёнными карточками и нижней навигацией.

## Данные и резервные копии

Рецепты, избранное, история, покупки и настройки сохраняются локально через AsyncStorage. Защищённая запись и восстановление обрабатывают ошибки чтения и записи. Для крупных нативных данных используется хранение частями.

Данные разных устройств, браузеров и профилей браузера независимы. Для переноса используется файл резервной копии. Очистка данных приложения или сайта может удалить локальный профиль.

В текущей версии откройте **Настройки → Резервные копии**.

- **Создать резервную копию** сохраняет полный профиль в формате `recipes-profile-backup`, версия 1. В файл входят рецепты, ингредиенты, избранное, история с сохранёнными оценками и заметками, покупки с количествами, единицами, галочками и порядком, а также пользовательские настройки.
- **Восстановить из файла** показывает содержимое и предупреждение перед заменой текущего профиля. Замена выполняется после явного подтверждения.
- Старые файлы `recipes-backup`, версия 1, продолжают поддерживаться. Их загрузка добавляет рецепты и историю с обработкой дубликатов.
- Повторная загрузка одного файла обрабатывает дубликаты и сохраняет количества покупок без удвоения.
- Web использует браузерное сохранение файла, Android/iOS — нативные файловые адаптеры. Сохранение и восстановление на Android проверены в самостоятельной APK.

**Файл не зашифрован. Храните его в безопасном месте.** Автоматическая облачная синхронизация и автоматические резервные копии отсутствуют. Работа с очень большими файлами ограничена памятью и свободным местом устройства.

## Локальный запуск опубликованной ветки

Нужны Git, Node.js и npm. Последние локальные проверки ветки разработки выполнялись на Node.js 24.21.0. Версия Node.js должна соответствовать требованиям установленного Expo и поддерживать используемый в тестах TypeScript.

```bash
git clone https://github.com/Nesterov-art/recipes.git
cd recipes
npm ci
npm start
```

Сервер разработки Expo предоставляет запуск в браузере и подключение мобильных устройств.

```bash
npm run web
npm run android
npm run ios
```

`android` и `ios` запускают сервер Expo с выбором платформы. Для Android нужен доступный эмулятор или подключённое устройство. iOS Simulator требует macOS и Xcode. Мобильный запуск через Expo Go требует совместимой версии SDK и набора нативных модулей.

Самостоятельная APK содержит приложение и запускается без Metro и Expo Go.

## Проверки

```bash
npm test
npm run typecheck
npm run lint
```

Браузерные сценарии выполняются через Playwright.

```bash
npx playwright install
npm run test:e2e
npm run test:visual
npm run test:e2e:report
```

[Руководство по браузерному тестированию](docs/browser-testing.md) описывает окружение и работу со снимками.

При проверке локальной ветки 13 ноября 2026 года после исправления двух P2 в APK №8 выполнены TypeScript, ESLint и 254 unit-теста. Выбранные E2E дали 75 успешных проверок и 9 платформенных пропусков. Нативно проверены форма при шрифте 100%/130%, клавиатура, прокрутка, покупки, свайпы, drag, сохранение порядка и профиля при обновлении APK №7 → №8. Результаты относятся к проверенному рабочему дереву ветки разработки.

WebKit с мобильным viewport проверяет браузерное поведение. Нативный iOS runtime и установленная PWA на реальном iPhone требуют отдельных проверок.

## Структура текущей разработки

```text
src/
  app/          Экраны и маршруты Expo Router
  components/   Общие компоненты интерфейса
  constants/    Типы рецептов, переводы и темы
  context/      Состояние приложения и локальное хранение
  hooks/        Общие React hooks
  utils/        Обработка рецептов, покупок, копий и unit-тесты
e2e/            Браузерные сценарии Playwright
scripts/        Служебные команды и проверки
plugins/        Конфигурационные плагины Expo и Babel
assets/         Иконки и иллюстрации
public/         Ресурсы Web/PWA
docs/           Документация проекта
```
