# Рецепты

Минималистичное приложение для хранения рецептов, случайного выбора блюда и ведения списка покупок. Работает на React Native, Expo и Expo Router, поддерживает iOS, Android и web/PWA.

## Возможности

- создание, редактирование, поиск и сортировка рецептов;
- светлая и тёмная темы, русский и английский языки;
- любимые рецепты и история приготовлений с оценками и заметками;
- Smart Random для выбора следующего блюда;
- список покупок с объединением одинаковых продуктов, свайпом для удаления и изменением порядка;
- подбор рецептов по продуктам из списка покупок;
- локальное хранение данных через AsyncStorage.

## Запуск

```bash
npm install
npx expo start
```
