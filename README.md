# Рецепты

Персональная книга рецептов, помощник выбора блюда и связанный с рецептами список покупок. Сохраняйте любимые блюда, отмечайте приготовления и решайте ежедневный вопрос «Что приготовить?».

**[Открыть приложение](https://neyroshi-recipes.expo.app)**

Опубликованная web/PWA-версия работает независимо от компьютера разработчика. Проект также содержит приложение на Expo для iOS и Android.

## Возможности

### Книга рецептов

- Готовые стартовые рецепты и создание собственных.
- Редактирование и удаление рецептов с уведомлениями о результате.
- Название, время приготовления, категория, ингредиенты и пошаговые инструкции.
- Поиск одновременно по названию и ингредиентам.
- Фильтры: все рецепты, любимые, завтрак, обед, ужин и быстрые блюда до 15 минут включительно.
- Сортировка: сначала новые, А–Я и Я–А.
- Количество рецептов и среднее время приготовления на главной странице.

### «Что приготовить?»

Умный случайный выбор учитывает активный поиск, фильтр и историю приготовления:

- не предлагает один рецепт два раза подряд, если есть другие подходящие;
- повышает вероятность блюд, которые ещё не готовили;
- чаще предлагает давно не готовившиеся блюда и реже — недавно приготовленные;
- сохраняет случайность и позволяет запросить другой вариант.

Подбор выполняется локально: для выбора блюда не нужен внешний сервис.

### Любимые и история приготовления

Рецепт можно отметить сердцем и найти через фильтр «Любимые».

Действие «Я приготовил» сохраняет отдельную запись с датой и временем. По желанию можно добавить оценку — 😕 не понравилось, 🙂 хорошо или 🤤 отлично — и личную заметку.

На странице рецепта доступны число приготовлений, дата последнего, последняя оценка и заметка, а также переход к полной истории. Новые приготовления не перезаписывают предыдущие.

### Список покупок

- Добавление продуктов вручную или из рецепта с выбором нужных ингредиентов.
- Редактирование названия, количества и единицы измерения.
- Нормализация названий и объединение одинаковых продуктов.
- Суммирование количества с приведением совместимых единиц: например, граммов и килограммов.
- Сохранение отдельных позиций при несовместимых единицах.
- Отметка купленного и очистка отмеченных позиций.
- Удаление свайпом и изменение порядка перетаскиванием.
- Сохранение списка и порядка позиций после закрытия приложения.

### Подбор по продуктам

Приложение сопоставляет продукты из списка покупок с ингредиентами рецептов, показывает совпадения и недостающие ингредиенты. Сначала отображаются блюда с большей долей совпадений.

Сопоставление выполняется по нормализованным названиям: количество продуктов и отметка «куплено» не учитываются. Список покупок не является учётом запасов.

### Настройки

- Русский и английский интерфейс.
- Три размера текста.
- Сохранение пользовательских настроек.

## Локальный запуск

Нужны Git, Node.js и npm. Для запуска тестов используйте Node.js 22.18+ с поддержкой выполнения TypeScript без отдельного сборщика; версия Node.js также должна соответствовать требованиям установленных зависимостей Expo.

```bash
git clone https://github.com/Nesterov-art/recipes.git
cd recipes
npm ci
npm start
```

`npm ci` устанавливает зависимости по существующему lock-файлу. `npm start` запускает сервер разработки Expo.

Запуск в браузере:

```bash
npm run web
```

Для мобильного запуска можно открыть проект через Expo Go совместимой версии или использовать подготовленный эмулятор:

```bash
npm run android
npm run ios
```

Android требует доступного устройства или эмулятора. iOS Simulator запускается на macOS с Xcode; на Windows для проверки iOS используйте физическое устройство через Expo Go.

### Проверки

```bash
npm test
npm run typecheck
npm run lint
```

Существующие автоматические тесты проверяют обработку списка покупок и сопоставление рецептов с продуктами.

## Структура проекта

```text
src/
  app/          Экраны и маршруты Expo Router
  components/   Общие компоненты интерфейса
  constants/    Стартовые рецепты, переводы и темы
  context/      Состояние рецептов, покупок, настроек и уведомлений
  utils/        Логика выбора блюд, обработки продуктов и тесты
assets/         Иконки и изображения приложения
public/         Web-манифест, HTML и иконки PWA
```

## Хранение данных и ограничения

Рецепты, любимые, история приготовления, список покупок и настройки хранятся локально через AsyncStorage.

- Учётных записей и облачной синхронизации нет.
- На разных устройствах, в разных браузерах и профилях браузера будут отдельные данные.
- Очистка данных сайта или приложения может удалить сохранённую информацию.
- Автоматическое облачное резервное копирование и пользовательский экспорт/импорт данных не реализованы.

Локальное хранение сохраняет данные между запусками, но не заменяет резервную копию.

## Статус проекта

Опубликованная PWA с реализованными основными сценариями: хранение рецептов, выбор блюда, история приготовления и покупки. В `package.json` и конфигурации Expo указана версия **1.0.0**.

Текущий фокус — обратная связь тестеров, исправление ошибок и доведение пользовательского опыта. Наличие настроек iOS и Android в проекте само по себе не означает публикацию в App Store или Google Play.
